本專案為崔董專屬打造之 2027 年 2 月倫敦・巴黎十日雙城遊行動導航網頁（Mobile-first Travel Guide）。
捨棄刻板的 AI 霓虹科技感，採用生活風格誌典雅質感的紙感米白底色、英倫海軍藍與巴黎陶土橘莫蘭迪色調，專為手機隨身查閱優化。

## 核心設計特色 (Design Philosophy)

1. **拒絕 AI 感，回歸旅人本質 (Human-first Aesthetic)**：
   - 溫潤舒適的高對比閱讀排版，戶外行走或陽光下單手滑動依然清晰。
   - 簡約時間軸、明確的交通樞紐轉乘塊與票券狀態標籤（已訂妥 / 待預訂）。
2. **一目了然的五大專區切換**：
   - **📅 每日行程 (Itinerary)**：D1 至 D10 快速切換，完整涵蓋倫敦 3 晚與巴黎 5 晚核心動線。
   - **🚆 交通全覽 (Transit Hub)**：長榮航空直飛班機 (BR087 / BR088)、歐洲之星穿梭 (Eurostar 9023 及回程建議)、雙城地鐵與機場接駁避坑秘笈。
   - **🏨 住宿資訊 (Hotels)**：倫敦 Assembly Leicester Square 與巴黎住宿，支援一鍵複製地址、電話與 Google Maps 導航。
   - **🎫 票券與待辦 (Checklist)**：UK ETA、迪士尼一日雙園、博物館預約與出國行李清單。
   - **🆘 緊急聯絡 (Emergency)**：外交部急難專線、駐英／駐法代表處緊急電話、當地警消直撥。
3. **離線與隨身友善 (Mobile-friendly)**：
   - 支援原生點擊一鍵複製電話、地址與路線資訊。
   - 整合雙城冬令時差提示與穿搭提醒。
